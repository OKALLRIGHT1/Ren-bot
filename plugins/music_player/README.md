# 音乐播放器

`plugins/music_player/` · 类型 `react` · 触发词 `播放音乐`

播放本地音乐。明确歌名填歌名；要推荐填「推荐」；随便听填「随机」。只评价歌曲时不要调用。

## 调用方式

| 项 | 值 |
| --- | --- |
| 触发词 | `播放音乐` |
| LLM 指令 | `play_music` |
| 插件类型 | `react` |
| 别名 | `播放`、`放歌`、`来首`、`点歌`、`整首`、`听歌`、`听一首`、`放一下`、`放给我听`、`想听`、`听听`、`放`、`听`、`歌`、`曲`、`音乐`、`BGM` |
| 超时 | 30 秒 |
| 默认启用 | 是 |

示例：

```
[CMD: play_music | 推荐]
```
