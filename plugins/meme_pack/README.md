# 表情包库

按关键词/情绪选表情包，QQ 里可以手动发；私聊回复后也可能自动跟一张。

## 怎么用

```
/表情包 狡猾
/发表情
/随机表情
/导入表情包 D:\memes
/表情包统计
```

## 权限

- 本地可导入和统计
- QQ 仅主人手动发；群聊需要 @
- 自动发送默认只在私聊

## 要填的配置

打开 **插件管理 → 表情包库**：

| 项 | 说明 |
| --- | --- |
| 启用自动表情包 | 默认开。QQ 私聊回复后按概率追加一张 |
| 自动发送概率 | 0–1，默认 0.12 |
| 表情包选择模型 | 留空跟主程序聊天路由 |

不用填 API Key。先 `/导入表情包` 一个文件夹，或把图放到插件自带的 `assets/`。
