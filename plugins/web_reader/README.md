# 网页解析

给定一个链接，抓标题、域名和正文摘要。要「网上搜什么」请用「联网搜索」；要查二次元设定请用「萌娘百科」。

## 怎么用

- `读一下这个网页 https://example.com/article`
- `解析链接 https://...`
- 直接把 URL 给她也可以

## 权限

- 本地可用
- QQ 仅主人；群聊需要 @

## 要填的配置

打开 **插件管理 → 网页解析**：

| 项 | 说明 |
| --- | --- |
| 请求超时 | 默认 12 秒 |
| 正文最大字符 | 默认 2400 |

不用填 API Key。打不开的站点、需要登录的页面会失败。
