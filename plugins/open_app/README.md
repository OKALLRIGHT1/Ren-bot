# 快速启动

`plugins/open_app/` · 类型 `direct` · 触发词 `打开`

直接打开本地软件（仅信任列表；群聊禁用；管理员仅私聊）

## 调用方式

| 项 | 值 |
| --- | --- |
| 触发词 | `打开` |
| LLM 指令 | `open_app` |
| 插件类型 | `direct` |
| 别名 | `启动` |
| 超时 | 6 秒 |

示例：

```
[CMD: open_app | 计算器]
```
