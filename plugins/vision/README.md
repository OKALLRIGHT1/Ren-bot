# 屏幕

两件事：让她**看**当前屏幕或摄像头并分析；在 QQ 里把屏幕**发回**给你。

## 怎么用

让她看并分析（本地或 QQ 都行）：

- `看看屏幕`、`分析一下当前截图`
- `拍一张`、`看看摄像头`

在 QQ 里把图发回来（只发给主人，不进群）：

- `截图发我`、`把屏幕发给我`、`截屏给我`
- 可临时说范围：`截图发我 主屏`、`截图发我 全部屏`、`截图发我 第2屏`

「看看屏幕」是分析给她自己看；「截图发我」是把图传到你的 QQ。

## 权限

- 本地：可以让她看屏幕 / 摄像头
- QQ 回发截图：仅主人；群聊需要 @
- 其他人不能把你的屏幕要走

## 要填的配置

打开 **插件管理 → 屏幕**：

| 项 | 填什么 |
| --- | --- |
| 默认截图范围 | `primary` 主屏 / `all` 全部屏 / `monitor` 指定第 N 块 |
| 默认屏幕序号 | 选 `monitor` 时生效，从 1 开始 |
| 附带当前窗口标题 | 回发 QQ 时是否加一行当前窗口名 |

不用填 API Key。分析画面用的是你在「聊天模型」里配好的视觉模型。
