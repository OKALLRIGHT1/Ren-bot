## 🌟 核心特性

- **🎭 Live2D 拟真桌面角色**：支持多套服装与模型无缝切换、多动作随机情绪表达、实时语音口型同步（Lip-sync）、气泡交互以及空闲动作随机切换。
- **🎨 现代 macOS 风格设置中心**：内置多套高质感主题（Frost 雾白玻璃、Indigo 靛蓝、Sakura 樱花、Emerald 极光、Cyberpunk 赛博朋克等），提供完整的圆角卡片分层设计与原生级视觉体验。
- **🧠 统一模型目录与任务路由（Task Router）**：
  - 支持多提供商集中管理（OpenAI、DeepSeek、Gemini、Claude、Ollama 等接口统一配置，一键测试连通性）；
  - 支持用途标签（闲聊、推理/工具、摘要压缩、画图、图生图、代码、翻译、视觉理解、向量）；
  - 针对每个任务链路独立配置模型链与故障转移（主备无缝回退）。
- **🐧 QQ / NapCat 智能机器人接入**：
  - 支持通过 OneBot / NapCat 协议接入 QQ 私聊与群聊；
  - 自动支持反向 WebSocket 与 HTTP Webhook 双入站模式；
  - 严格的主人身份识别、黑白名单控制、图片多模态视觉理解、概率语音回复，且 QQ 对话来源与本地桌面动作智能解耦。
- **🔌 MCP（Model Context Protocol）扩展支持**：
  - 支持添加本地进程（`stdio`）与远程服务（`streamable_http`）的标准 MCP 工具服务器；
  - 动态建立会话，连接稳定可靠，零僵尸进程泄漏。
- **⏰ 桌面感知与久坐防沉迷**：
  - 实时采集桌面活动状态并在桌面端精准展示「工作时长」；
  - 智能久坐休息提醒：达到设定时间后自动弹出关怀窗口，支持角色定制化话术与专属表情包联动。
- **📚 长期记忆与本地知识库**：
  - SQLite 作为唯一事实源，支持向量语义检索、人物动态画像建模与每日自动生成日记；
  - 本地知识库支持将各类文档一键解析并构建语义索引库，闲聊与专业问答按需召回。
- **🛠️ 丰富的可扩展插件体系**：
  - 支持任务管理、倒计时番茄钟、联网搜索、网页抓取总结、邮件收发、音乐播放、系统监控、副脑复杂任务委托（Delegate）等强大插件能力。
- **🚀 极速平滑无感启动**：
  - 内置防闪烁启动器，启动时无黑框控制台闪烁，配备精致的居中置顶进度条小窗，就绪后平滑淡出。

## 🚀 快速启动指南

程序提供三种启动方式，满足日常使用与二次开发需求：

### 方式一：独立安装包（开箱即用，推荐普通用户）

如果您使用的是生成的 Windows 安装包（如 `Ren-Bot-Setup-v1.0.0.exe`）：
1. 双击运行安装程序，按提示选择安装目录（默认安装到当前用户程序目录，无需管理员权限）；
2. 安装程序会自动释放内置的独立运行环境与核心文件，并自动创建桌面快捷方式；
3. 双击桌面快捷方式即可直接启动，无需在电脑上预装 Python、Conda 或编译工具。

### 方式二：无控制台静默启动（推荐日常桌面使用）

在仓库根目录下：
- **双击运行 `Live2D-Suzu.exe` 或 `ren-bot.exe`**；
- 或者**双击运行 `启动-无窗口.vbs`**。

> **启动体验**：
> 启动器会以完全静默的后台模式拉起后端核心服务，并在屏幕正中央优雅弹出半透明的启动进度小窗，实时显示环境校验、依赖检查、数据库加载与 Live2D 桌面形象就绪状态。后端服务就绪后，小窗平滑淡出并自动展开桌面角色，全程无任何黑框命令行闪烁。

### 方式三：命令行 / 开发者启动（方便调试与日志查看）

在仓库根目录下，打开终端运行：

```bat
启动.bat
```

或直接执行 Python 入口：

```bash
python boot.py
```

> **说明**：
> `boot.py` 为全功能引导入口，会自动完成环境校验、端口检测与核心服务生命周期管理，并在终端打印彩色日志流。`python main.py` 仍可作为纯守护进程入口。

## ⚙️ 开发环境配置（源码运行）

如果您从 Git 仓库拉取源码运行，请按照以下步骤配置运行环境：

### 1. 自动配置脚本

双击运行仓库根目录下的：

```bat
安装环境.bat
```

脚本会自动检测本机环境。若未安装 Python，会尝试通过系统包管理器安装；随后会自动创建隔离的 Python 运行环境并安装 `requirements.txt` 中的所有依赖项。

### 2. 手动创建环境（推荐 Conda）

```bash
# 1. 创建 Python 3.10 环境
conda create -n live2d-llm python=3.10 -y
conda activate live2d-llm

# 2. 安装 Python 核心依赖
pip install -r requirements.txt
```

### 3. 配置密钥与环境变量

从模板复制并生成 `.env` 文件：

```bash
cp .env.example .env
```

在 `.env` 中填入您的基础密钥和配置（也可稍后直接在 GUI 设置中心中可视化修改）：

```ini
# 主模型 API Key（可填写 OpenAI / DeepSeek / 硅基流动 等兼容 API）
OPENAI_API_KEY=sk-your-api-key-here
OPENAI_BASE_URL=https://api.deepseek.com/v1

# 访问安全 Token（用于本机 HTTP/WS 校验，默认自动生成）
GUI_ACCESS_TOKEN=your_secure_random_token_here
```

## 🖥️ 设置中心使用详解

点击悬浮球或桌面角色托盘图标，选择 **「偏好设置」**，即可进入图形化设置中心。

### 1. 界面主题与显示
- **多套视觉主题**：可随时切换 macOS 风格的「Frost (雾白玻璃)」、「Indigo (靛蓝)」、「Sakura (樱花)」、「Cyberpunk (赛博朋克)」等；
- **全窗口原生渲染优化**：所有二级弹窗（如添加模型、路由编辑、服务配置）及消息通知框均已配置抗穿透实心背景，彻底解决 Windows DWM 底板发黑问题；
- **背景图与亚克力效果**：支持自定义设置窗口与主控制面板的毛玻璃透明度及壁纸。

### 2. 聊天模型与提供商管理（LLM）
- **+ 新增提供商**：统一录入供应商的 Base URL 与 API Key（例如 DeepSeek、OpenAI、SiliconFlow、Ollama 等），模型无需重复填写密钥；
- **添加 / 编辑模型**：
  - **模型用途标签**：可针对模型自由勾选「闲聊」、「推理/工具」、「总结」、「联网搜索」、「视觉理解」、「画图」、「代码」、「翻译」或「向量」；
  - **连通性探测**：弹窗右下角提供「测试连接」按钮，可一键实时测探端点延迟、HTTP 状态码及上游响应。
- **智能任务路由（Task Router）**：
  - 可对闲聊主回复、工具规划、语言翻译、回复润色、屏幕分类、图像生成等不同任务分别设置模型调用链；
  - 当首选模型响应超时或失败时，系统自动无缝顺延降级至备选模型。

### 3. 外部服务自启托管（External Services）
设置中心支持集中管理并监控本机运行的三大常用配套服务：
- **Ollama**：用于本地大语言模型与 BGE-M3 本地向量嵌入服务；
- **GPT-SoVITS**：用于本地拟真高音质角色语音合成 API；
- **NapCat**：用于 QQ 机器人快速接入的无头客户端。
> 支持配置服务启动路径、健康检查 URL、启动等待时间，并可设定「随本程序自启」以及「退出时自动停止进程」。

### 4. 桌面感知与久坐关怀
- **工作时长统计**：桌面端实时采集键鼠与窗口活动，状态条显示「工作了多久」；
- **久坐弹窗提醒**：支持自定义连续工作提醒阈值（默认 60 分钟）、休息冷却时间以及自动关闭倒计时；
- **个性化表现**：支持联动 Live2D 专属提醒动作、角色语音关怀以及自定义久坐表情包图片。

## 🐧 QQ / NapCat 接入全流程

通过接入 NapCat，您可以让角色变身为 24 小时在线的 QQ 个人助理。

### 1. 网络连接配置
在设置中心 **「MCP / QQ」** 分页中配置：
- **Webhook Host**：`127.0.0.1`
- **Webhook Port**：`8095`（本程序开放给 NapCat 的监听端口）
- **Webhook Path**：`/chat/napcat`
- **NapCat API Base**：`http://127.0.0.1:3000`（NapCat 本地 HTTP API 端口）

> **网络入站**：本程序在同一端口（`8095`）下**同时支持** HTTP Webhook 上报与反向 WebSocket 连接，无需额外开启新端口。

### 2. NapCat 端配置步骤
1. 打开 NapCat 的 Web 管理面板（通常为 `http://127.0.0.1:6099/webui/`）；
2. 进入「网络配置」，新增一条 **HTTP 上报**：
   - URL 填写：`http://127.0.0.1:8095/chat/napcat`
   - 上报格式选择：`JSON`
3. 或新增一条 **反向 WebSocket**：
   - 地址填写：`ws://127.0.0.1:8095/chat/napcat`
4. 保存配置后重载，即可完成通道双向打通。

### 3. 安全策略与交互原则
- **副号原则**：强烈建议使用专用小号登录 NapCat，避免主号风险；
- **权限隔离**：支持配置「主人 QQ 号」。文件发送、屏幕截图、系统命令控制等敏感高权限插件仅对主人开放；
- **群聊免打扰**：群聊建议开启「群聊仅响应 @我」并启用群白名单；
- **动静解耦**：QQ 来源的消息**默认不会驱动**本地屏幕上的 Live2D 做动作或发出本地语音朗读，确保在外面用手机聊 QQ 时不会打扰电脑前的环境。

## 🔌 MCP（Model Context Protocol）扩展

本程序原生支持 Anthropic 开源的 MCP 标准协议，能将任意外部工具库接入助手的推理调用链中。

### 1. 支持的服务类型
- **本地 stdio 模式**：通过子进程拉起本地命令行工具（如 Node.js / Python 脚本）；
- **远程 streamable_http 模式**：通过 HTTP/SSE 协议连接远程或内网 MCP 伺服进程。

### 2. 配置方式
在设置中心 **「MCP / QQ」** 中点击「新增 MCP 服务器」：
- **名称**：自定义工具集标识（如 `filesystem-tools`）；
- **传输模式**：选择 `本地进程 (stdio)` 或 `远程 HTTP`；
- **命令行 / URL**：填入可执行命令或服务端网络地址；
- **环境变量**：支持为 MCP 进程注入专有环境变量（如 `GITHUB_TOKEN=ghp_xxx`）。

### 3. 运行机制
- 采用**稳优先**的动态会话管理架构，每次列举与调用工具时均维持干净状态，彻底杜绝进程句柄悬挂与长连接假死问题。

## 🎭 角色换装与动作管理

进入设置中心 **「角色管理」**，可进行可视化的人设与交互动作配置：

- **动作优先级机制**：
  $$\text{服装映射} > \text{角色默认映射} > \text{模型自动推导} > \text{全局默认映射}$$
- **多动作随机播放**：同一个情绪（如 `happy`、`shy`、`angry`）可勾选多个模型自带动作，角色触发该情绪时会自动随机抽取其中一个播放，大幅提高生动度；
- **口型同步（Lip-sync）**：无论是使用 Edge TTS 还是本地 GPT-SoVITS 语音，均能将音频振幅实时转换为 Live2D 参数映射，呈现精准口型；
- **多角色支持**：支持配置多个独立角色，并在右键菜单中一键切换。

## 🧠 记忆系统与知识库

### 1. 三层长期记忆设计
- **核心事实源**：所有聊天历史、事实画像与重要事件均结构化存储在 `memory/memory.sqlite` 中；
- **语义向量检索**：支持对接本地 Ollama（如 `bge-m3`）或在线嵌入模型。检索时按当前对话主题精准提取最相关的历史记忆片段，避免长文本上下文被无关历史污染；
- **自动日记总结**：每天定时触发日记归纳流程，将当天的活动和交流要点压缩并沉淀至长期记忆库。

### 2. 本地知识库操作
- 支持导入外部设定文本、专有名词库、业务资料（`.txt`、`.md`、`.pdf` 等）；
- 在知识库管理页中点击「重建索引库」与「一键学习」，即可建立本地向量切片；
- 闲聊时系统保持自然对话，仅在检测到与专业知识相关的明确提问时才检索并注入知识片段。

## 🧩 插件系统与副脑委托

### 1. 插件体系架构
所有插件存放于 `plugins/<plugin_name>/` 目录下，包含两部分：
- `config.json`：声明元数据、参数选项、命令别名与权限控制；
- `plugin.py`：实现核心逻辑并声明能力接口（`get_capabilities()`）。

### 2. 四大插件运行机制
1. **`react`（模型自主触发）**：模型根据用户意图在输出中生成 `[CMD: tool_name args]` 工具指令，由系统拦截执行；
2. **`direct`（关键词直达）**：用户输入命中指定命令或关键词时立即执行，跳过大模型推理开销；
3. **`observe`（被动感知）**：用于环境信息感知、画面变化监测等，不直接替代主回复内容；
4. **`delegate`（副脑委托模式）**：
   - 适用于多步推理、联网搜索检索、工作区代码修改等复杂耗时任务；
   - 由主脑负责保持人设与自然语言沟通，将具体繁重任务委托给后台副脑逐步调用工具执行，并通过状态插件查看进度。

## ❓ 常见问题排查

- **Q1：双击运行后没有反应？**
  - 首先检查任务管理器中是否存在 `python.exe` 进程。若初次运行，可在控制台执行 `启动.bat` 查看是否有 Python 缺失或依赖未装全的报错；
  - 检查 `logs/setup_env.log` 或 `logs/launcher.log` 中的日志记录。
- **Q2：模型提示连接超时或 API 错误？**
  - 进入「设置中心 → 聊天模型」，点击「测试连接」检查网络通畅度；
  - 如果使用的是国内代理中转地址，确保 Base URL 后带有 `/v1`（如 `https://api.example.com/v1`）；
  - 检查网络代理或防火墙是否放行。
- **Q3：设置窗口中弹窗或提示框显示异常？**
  - 最新版本已全面修复 Windows DWM 窗口透明度导致的黑底问题。若依然异常，请确认使用的是最新安装包或已拉取最新代码。
- **Q4：QQ 机器人没有收到上报消息？**
  - 确认 NapCat 的上报地址是否准确填写为 `http://127.0.0.1:8095/chat/napcat`；
  - 检查设置中心里的 `NAPCAT_ENABLED` 是否已开启，端口 `8095` 是否被其他程序占用。
- **Q5：久坐提醒没有弹出？**
  - 久坐提醒依赖桌面端活动监控，请确认设置中心中已开启「屏幕传感器」与「久坐提醒」开关；
  - 默认冷却时间为 60 分钟，只有在持续处于活动状态且未达休息阈值时才会按计划弹出。
