# 全局健康中心 GUI 设计

## 目标

让用户无需调用 HTTP 接口，就能在现有 Qt 主界面看到程序总体健康状态，并查看各运行组件的状态、摘要与更新时间。

## 范围

- 在主界面顶栏增加红、黄、绿健康状态入口。
- 点击入口打开只读的“运行健康中心”窗口。
- 窗口显示总体状态，以及组件名称、有效状态、摘要、更新时间。
- 顶栏和已打开的详情窗口每 10 秒刷新。
- 读取失败时明确显示“状态读取失败”，但不影响聊天与其他 GUI 功能。
- 不修改健康状态判定，不探测外部服务，不重启当前正在运行的旧程序。

## 数据与边界

GUI 直接读取 `Live2DApplication.runtime_health` 的线程安全 `snapshot()`，与 `/gui/runtime/status` 共用同一事实源。GUI 只格式化和展示数据，不通过需要 Token 的 HTTP 接口回环请求，也不自行判定组件是否健康。

## 交互

- `healthy`：绿色，文案“运行健康”。
- `degraded`：黄色，文案“运行需注意”。
- `offline`：红色，文案“运行异常”。
- 暂无健康中心绑定时：灰色，文案“健康状态未知”。
- 详情按异常、恢复中、健康、已禁用的优先级排列，方便先看到需要处理的项目。

## 验证

- 纯函数测试覆盖状态文案、颜色、排序、有效状态和异常输入。
- Qt 离屏测试覆盖顶栏入口刷新和详情窗口表格刷新。
- 运行 GUI 相关目标测试后，再运行完整 pytest。
